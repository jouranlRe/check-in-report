# 期刊签收统计报告

## 文件说明

| 文件 | 说明 |
|---|---|
| `index.html` | 期刊签收统计报告页面，双击即可在浏览器打开 |
| `styles.css` | 页面样式 |
| `scripts.js` | 页面交互脚本 |

> ⚠ 本目录为自动生成目录。运`extract_report.bat从journal_report.html生成。手动修改将被覆盖。

## 概览卡片

页面顶部 10 张卡片展示核心统计数据：期刊总种数、中文/外文期刊数、到刊总期数、疑似漏发期数、本月签收情况、整体完成率、超 60 天未签收期刊数、零签收期刊数。

## 到刊趋势图表

两幅折线图展示 2026 年每月到刊的种数和期数变化趋势，中文和外文分色显示。

## 异常台账

四个标签页：
- **漏刊预警** — 列出疑似漏发的期刊及漏发期次详情，可按刊名、漏发数量排序
- **停刊汇总** — 列出已停刊的期刊及停刊期数，可按刊名排序
- **合刊统计** — 列出存在合刊情况的期刊及合刊说明，可按刊名排序
- **超 60 天无签收** — 列出长期未签收的期刊及最后到刊日期，可按刊名、最后到刊时间排序

## 期数网格

中文和外文分 tab 展示，每行一本期刊，用彩色方块表示签收状态：绿色=已签收、黄色=合刊、红色=停刊、灰色=未到。连续合刊自动合并显示（如 `5-6` 代表第 5、6 期合刊），合并后可点击查看详情。

左侧固定列同时给出**邮发号（外文为刊号）+ 刊名 + 完成率**（已到/应到，绿≥100%、橙≥60%、红<60%）：

- **固定不滚动** — 横向拖动期号时，邮发号/刊名/完成率始终留在左侧
- **列头排序** — 点击「邮发号」「刊名」「完成率」任意列头即可排序，再点一次切换升/降序，▲▼ 指示当前方向
- **刊名搜索** — 输入刊名实时过滤，匹配行高亮显示
- **拖拽滚动** — 按住方块区域左右拖拽横向查看
- **点击查看** — 点击任意方块弹出详情窗，显示刊名、期号、签收状态和对应的到刊时间
- **漏发/停刊提示** — 鼠标悬停在某一行上，可看到该刊的漏发期号与停刊期号（各刊详情也在「异常」页签中汇总）

## 排架布局

按实际书架位置展示所有期刊的签收状态。A/B/C/D 四架通过标签按钮切换，每格展示：刊名、已到/总期数和完成率、进度条、迷你方块（每期签收状态）。

- **颜色标识** — 绿色=最近签收（最新批次）、红色=含停刊/漏发、黄色=有未到期、灰色=未到/空
- **颜色优先级**（高→低）：绿 > 红 > 黄 > 灰
- **卡片排列** — 同一架内 5 列，每列多行排列

## 签收时间线

按日期倒序展示所有签收记录，每天汇总展示当日的签收期刊及期次。**同一天同一本刊的多期会合并成一条**，例如「三联生活周刊：38期、39期、40期、41期」；日期后括号内的数字是该批次签收的总期数（合并前后的口径一致）。

- **刊名搜索** — 输入刊名实时过滤
- **月份筛选** — 按下拉菜单选择月份过滤
- **动态统计** — 右上角实时显示当前筛选结果的总种数和总期数（按合刊里的实际期数累计）

## 页面导航

页面左侧（手机端底部）设有悬浮导航栏，包含概览、趋势、异常、网格、**排架**、时间线六个快捷入口，滚动时自动高亮当前所在区块。

标签页切换时 URL 自动记录状态，刷新页面后自动恢复。
